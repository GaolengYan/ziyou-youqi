ABOUT THE FREEDOM PROJECT

让每个长期选择，
多一点理解。

自由有期是一组面向中文读者的基础金融知识与情景工具。我们关注复利、FIRE 和生活选择之间的关系，让概念可以阅读，让假设可以检查。

说明更新：2026-11-11

在这里可以做什么

从财富自由与消费影响计算器出发，学习复利、通胀、费用、现金流与风险，再用复利积累、目标倒推和退休提取实验理解不同假设。本站不连接银行、不代客理财、不执行交易，也不提供针对个人情况的产品推荐。

FIRE 不是每个人必须选择的生活方式。本站希望帮助读者理解选择与约束，不用一个资产数字评价个人价值，也不把提前退休等同于停止一切工作。

内容与数字怎样产生

本站文章包含 AI 辅助整理的内容。概念尽量链接统计机构、监管机构或研究机构的原始资料；算例由本站构造，计算公式、情景输入与边界在正文中说明。自动化检查用于核对关键计算和页面链接，不等同于持证专业人士对个人方案的审核。

历史数据会注明统计区间与原始出处，教学假设会明确标注，不把它们写成用户平均值或未来预测。资料核验日期与修改日期随相应内容更新，不表示每个来源都在该日发布。发现错误时，应更正文中结论并重新检查受影响的计算与页面。

海外资料用于解释通用概念。养老金资格、税收、存款保障、产品可购买性和投诉处理均存在地区差异，应以适用地区的最新官方规则和实际文件为准。本站没有自动纳入这些制度。

输入在哪里，哪些会被保存

功能本站对输入的处理
首页财富自由与消费模拟在浏览器本机存储保存输入与演示模式，便于同一浏览器再次使用；可通过“清除”或浏览器网站数据设置移除。
复利、目标倒推、退休实验仅在当前页面即时计算，不主动保存输入；刷新或离开后不会由本站恢复。
学习中心文章筛选在本页筛选标题和摘要，不提交到搜索服务，不写入网址或本机存储。

这些输入不被本站计算代码发送到服务器，不连接银行，也不嵌入分享网址。在共用设备上使用首页时，请在结束后清除本机记录。浏览器扩展、设备同步与他人接触设备的行为不由本站控制。

托管与外部链接

网站由 GitHub Pages 提供静态托管。访问网页本身仍会向托管服务请求页面和资源，托管服务可能根据其政策处理 IP 地址等访问技术信息；“财务输入本机计算”不等于访问网站完全没有网络记录。本站目前未加入广告、分析追踪器、第三方字体或账号登录。

点击原始来源、GitHub 或其他外部链接后，将访问对应第三方网站，适用其自身规则。GitHub 相关处理可参阅 GitHub 隐私声明。

发现计算或内容问题

可以在 公开代码仓库的问题区 反馈。请提供页面链接、问题描述和虚构的最小复现数字；问题区是公开的，不要提交真实收入、银行账户、身份证、密码或其他敏感资料。本站没有要求你通过私信或转账来解锁工具。

公开可抓取并不意味着搜索引擎一定收录、排名或 AI 系统一定引用。本站也不对收益、退休时间或个人决策结果作保证。所有计算都应结合已公开的模型范围理解。
